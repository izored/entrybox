Welcome

The idea board that lives in your repo.

EntryBox is a tiny local server. One markdown file per project. A state machine. A UI that takes 3 seconds to understand.

No SaaS. No database. No account. Your entries never leave the machine.

Not a task manager. Not a planner. A drop box — log it now, work on it later.

The Problem

Ideas die in chat.

Feedback gets buried in Slack threads. GitHub Issues feel too formal for a shower-thought at 2am. Notion needs an account and another open tab.

You just want to write it down and have your AI agent know about it. Not manage it — just not lose it.

EntryBox doesn't manage your work. It holds it until you're ready.

How it works

Log. Park. Ship.

Every entry gets a unique ID, a type, and a state. You, or your AI agent, move it through states.

logged → review → wip → done
↘ error (if blocked)

Done entries timestamp themselves. The markdown file stays readable in any editor forever.

CLI & API

Works with your agent.

Your agent can update entry states directly. Two ways:

# CLI
python cli/entrybox.py update-state --project myproject --id ENTRY-0001 --state done
# REST API
PATCH http://localhost:3859/api/projects/myproject/entries
# Body: {"id": "ENTRY-0001", "state": "done"}

The entries.md file is plain markdown, so your agent can read it directly too.
