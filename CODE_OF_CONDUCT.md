# Code of Conduct

EntryBox adopts the **Contributor Covenant**, version 2.1, as its code of
conduct. The full text is the canonical document published here:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By taking part in this project (issues, pull requests, discussions, themes)
you agree to uphold it. In short: be respectful, assume good faith, and help
keep this a welcoming space for everyone regardless of background or experience.

## Reporting

To report a concern, contact the maintainer privately:

**dev@izo.red**

Reports are handled confidentially. The maintainer will review every report and
respond as outlined in the Covenant's enforcement guidelines.
